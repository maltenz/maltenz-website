## HBO Max Rollout (Web & React Native)

**Role:** Senior Frontend Engineer (Contract)  
**Platforms:** Web (React) & React Native (iOS / Android)  
**Focus:** Platform integration, feature rollout, performance, UI consistency  

I was contracted to lead the rollout of Sky’s new **HBO Max section** across all Sky Go platforms — including web and mobile applications built in React Native.

This was a high-visibility release requiring close collaboration with product, design, backend, and platform teams to deliver a seamless, premium streaming experience across devices.

### 🚀 What I Delivered

- Implemented the full HBO Max content section within the Sky Go ecosystem
- Built responsive UI components using React (Web)
- Extended and adapted shared components for React Native (iOS & Android)
- Integrated new content APIs and entitlement logic
- Ensured feature parity between web and mobile platforms
- Maintained high performance standards for streaming-heavy UI surfaces
- Worked within and extended an existing enterprise design system

### 🧩 Key Challenges

**Cross-platform consistency**  
Ensuring the HBO Max experience felt cohesive across web and mobile while respecting platform-specific interaction patterns.

**Performance & scalability**  
Streaming platforms demand fast load times and smooth browsing — especially for hero carousels, content rails, and media-heavy views.

**Enterprise codebase integration**  
The rollout needed to integrate cleanly into a mature production codebase without introducing regressions or impacting existing user flows.

### 🛠 Technical Stack

- React (Web)
- React Native (iOS / Android)
- TypeScript
- Modular component architecture
- API integration for dynamic content feeds
- CI/CD within an enterprise OTT environment

### 📈 Impact

The HBO Max rollout expanded Sky Go’s premium content offering and delivered a seamless branded experience across devices. The implementation maintained platform stability while introducing a major global content partner into the ecosystem.
