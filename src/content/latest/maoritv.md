## Full Website Rebuild

**Role:** Sole Frontend Engineer  
**Platform:** Web (React)  
**Architecture:** REST API + Firebase User Management  
**Build Tooling:** Vite + TypeScript  

I was the sole developer responsible for rebuilding the Māori Television website from the ground up.

This was a full greenfield project — architecture, implementation, performance optimisation, and release pipeline — all owned and delivered end-to-end.

This is the kind of work I pride myself on: clean foundations, strong architecture, and slick, responsive performance.

### 🚀 What I Delivered

- Designed and built the entire React application from scratch
- Integrated REST APIs for dynamic content delivery
- Implemented Firebase-based authentication and user management
- Built a scalable component architecture using TypeScript
- Implemented routing, state management, and persistence
- Delivered production builds across multiple environments (dev, QA, UAT, prod)
- Maintained CI/CD packaging and release versioning

### 🧱 Architecture & Stack

- **React 18**
- **TypeScript**
- **Vite** (fast build tooling & modern bundling)
- **Redux Toolkit** + state persistence
- **Firebase** (authentication & user management)
- **REST API integration**
- **Material UI (MUI)** + Emotion styling
- **Jest** for testing
- **SonarQube** integration for code quality
- Multi-environment build pipelines with structured release versioning

The project was structured for long-term maintainability, clear domain separation, and predictable state management.

### ⚡ Performance & Experience

Performance was a major focus from day one.

- Optimised bundle size and lazy-loaded routes
- Carefully managed API calls and caching behaviour
- Ensured smooth navigation across content-heavy pages
- Delivered a responsive experience across devices
- Maintained strong Lighthouse performance metrics

The result was a fast, modern streaming-ready web platform built to scale.

- Long-term maintainability

Building a national broadcaster’s platform solo required autonomy, accountability, and strong architectural thinking.
